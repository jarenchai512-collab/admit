# ระบบรับสมัครเรียนออนไลน์ (ประเภทโควตา) ประจำปีการศึกษา ๒๕๗๐
## วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์
### สังกัดสำนักงานคณะกรรมการการอาชีวศึกษา กระทรวงศึกษาธิการ

เว็บแอปพลิเคชันระบบรับสมัครเรียนออนไลน์ ออกแบบตามมาตรฐานหน่วยงานราชการและสถานศึกษา เรียบ สุภาพ น่าเชื่อถือ ใช้งานได้สมบูรณ์แบบทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ (Responsive Web Application) โดยมี **Google Apps Script** เป็น Backend, **Google Sheets** เป็นฐานข้อมูล และ **Google Drive** สำหรับจัดเก็บไฟล์แนบ

---

## ๑. แนวทางการออกแบบ (Design Principles)
* **โทนสีราชการสุภาพ:** สีหลักน้ำเงินเข้ม (`#1F3A5F`) บนพื้นหลังขาวและเทาอ่อน (`#F8F9FA`)
* **ไม่มีองค์ประกอบฉูดฉาด:** ปราศจากสีนีออน/ม่วง, ปราศจาก Gradient, ปราศจาก Glassmorphism, เงาไม่ฟุ้ง และไม่มี Emoji
* **ฟอนต์มาตรฐาน:** ใช้แบบอักษร **Sarabun** (Google Fonts) ขนาดอ่านสบายตา จัดช่องไฟเรียบร้อย
* **ส่วนหัวสถานศึกษา:** ตราสัญลักษณ์ทางการของวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ พร้อมชื่อวิทยาลัยเต็มและสังกัด สอศ.
* **เมนูหลัก ๔ รายการ:**
  1. **หน้าแรก:** แสดงประกาศวิทยาลัย, กำหนดการรับสมัคร, ระดับและสาขาที่เปิดรับ, เอกสารที่ต้องเตรียม, ข้อมูลติดต่อ
  2. **สมัครเรียน:** ฟอร์มใบสมัครจัดเป็นข้อ ๑ - ๖ ตามใบสมัครกระดาษต้นฉบับ
  3. **ตรวจสอบสถานะ:** ตรวจสอบผลการพิจารณาและอัปโหลดเอกสารแก้ไข
  4. **เจ้าหน้าที่:** พอร์ทัลจัดการงานทะเบียน, ตรวจสอบเอกสาร, บันทึกผล, สถิติแดชบอร์ด และส่งออกข้อมูล

## ๒. โครงสร้างและฟังก์ชันการทำงาน

### ๒.๑ ส่วนผู้สมัคร (Applicant Portal)
* **แบบฟอร์ม ๖ ข้อตรงตามต้นฉบับใบสมัครกระดาษ:**
  * **เลือกระดับชั้น:** ปวช. / ปวส. (สายตรง) / ปวส. (ม.6/ปวช. ต่างสาขา)
  * **ข้อ ๑ ผู้สมัคร:** คำนำหน้า, ชื่อ-สกุล, วัน/เดือน/ปีเกิด (พ.ศ.), เลขประจำตัวประชาชน ๑๓ หลัก
  * **ข้อ ๒ บิดา:** ชื่อ-สกุล, อายุ, อาชีพ
  * **ข้อ ๓ มารดา:** ชื่อ-สกุล, อายุ, อาชีพ
  * **ข้อ ๔ ที่อยู่ปัจจุบัน:** บ้านเลขที่, หมู่, ซอย, ถนน, ตำบล, อำเภอ, จังหวัด (ดรอปดาวน์ ๗๗ จังหวัด), รหัสไปรษณีย์, เบอร์โทรศัพท์ ๑๐ หลัก
  * **ข้อ ๕ กำลังศึกษา:** ระดับชั้น, โรงเรียนเดิม, ที่ตั้งโรงเรียน, ผลการเรียนเฉลี่ยสะสม (GPAX), สาขาวิชาเดิม
  * **ข้อ ๖ สาขาที่ประสงค์สมัคร:** ดรอปดาวน์เชื่อมโยงกับชีต Settings โดยอัตโนมัติ
    * *ปวช.:* เลือกได้ ๒ ลำดับ (ลำดับที่ ๑ และลำดับที่ ๒ ห้ามซ้ำกัน)
    * *ปวส.:* เลือก ๑ สาขาวิชา
* **ระบบตรวจสอบความถูกต้อง (Validation):**
  * ตรวจสอบความถูกต้องของเลขบัตรประชาชนด้วยสูตรคำนวณ Checksum 13 หลัก
  * ตรวจสอบการสมัครซ้ำด้วยเลขบัตรประชาชนเดิมในปีการศึกษา ๒๕๗๐
  * ตรวจสอบเบอร์โทรศัพท์ ๑๐ หลัก (ขึ้นต้นด้วย 0)
  * ตรวจสอบ GPAX ให้อยู่ระหว่าง 0.00 – 4.00
  * มีข้อความยินยอมการเก็บข้อมูลส่วนบุคคลตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล (PDPA)
* **ระบบอัปโหลดเอกสารหลักฐาน (JPG/PNG/PDF ไม่เกิน ๕ MB):**
  1. รูปถ่ายหน้าตรงขนาด ๑ นิ้ว (บังคับ)
  2. ระเบียนแสดงผลการเรียน (ปพ.๑) ๕ ภาคเรียน (บังคับ)
  3. สำเนาบัตรประชาชน หรือสำเนาทะเบียนบ้าน (บังคับ)
  4. เกียรติบัตร / ใบรับรองความสามารถพิเศษ (ไม่บังคับ)
* **หลังส่งใบสมัคร:**
  * ออกเลขที่ใบสมัครอัตโนมัติ เช่น `Q70-0001`
  * สร้างและดาวน์โหลด **ใบสมัครทางการขนาด A4 ในรูปแบบ PDF** ทันที พร้อมรูปถ่ายมุมขวาบน ช่องลงลายมือชื่อผู้สมัคร และรายการตรวจสอบเอกสาร
* **การตรวจสอบสถานะ:**
  * ระบุเลขบัตรประชาชน ๑๓ หลักเพื่อดูสถานะและข้อความแจ้งเตือนจากเจ้าหน้าที่
  * หากสถานะเป็น **"เอกสารไม่ครบ"** ผู้สมัครสามารถเลือกประเภทเอกสารและอัปโหลดไฟล์แก้ไขใหม่ได้ทันที

### ๒.๒ ส่วนเจ้าหน้าที่และผู้ดูแลระบบ (Staff & Administration)
* **ระบบเข้าสู่ระบบแบ่งสิทธิ์ (Role-Based Access Control):**
  * ผู้ดูแลระบบ (Admin)
  * เจ้าหน้าที่ทะเบียน (Officer)
* **ทะเบียนรายชื่อผู้สมัคร:**
  * ค้นหาแบบ Real-time (เลขที่สมัคร, ชื่อ-สกุล, เลขบัตร, โรงเรียนเดิม)
  * กรองตามระดับชั้น (ปวช., ปวส. สายตรง, ปวส. ม.6/ต่างสาขา) และกรองตามสถานะ
  * ดูรายละเอียดและเปิดดูไฟล์แนบของผู้สมัครได้ในหน้าต่างเดียว
* **การปรับปรุงสถานะและกระบวนการคัดเลือก:**
  * สถานะ: `รอตรวจสอบ` ➔ `เอกสารไม่ครบ` ➔ `ผ่านการคัดเลือก` ➔ `ไม่ผ่านการคัดเลือก` ➔ `มอบตัวแล้ว`
  * บันทึกหมายเหตุแจ้งผู้สมัคร
  * บันทึกประวัติการเปลี่ยนสถานะ (Audit Log) ระบุชื่อผู้ดำเนินการ วันและเวลา
* **ระบบมอบตัวและออกรหัสนักเรียน:**
  * เมื่อปรับสถานะเป็น "มอบตัวแล้ว" ระบบจะออกรหัสประจำตัวนักเรียน/นักศึกษาอัตโนมัติ (เช่น `70209010001`)
* **ระบบแจ้งเตือน (Notifications):**
  * ส่งแจ้งเตือนผ่าน LINE Notify และอีเมลเมื่อมีผู้สมัครใหม่และเมื่อสถานะเปลี่ยน
* **แดชบอร์ดสถิติและรายงานสรุป:**
  * ตัวเลขสรุป KPI ผู้สมัครทั้งหมด แยกตามระดับ แยกตามสถานะ
  * ชาร์ตแท่งสัดส่วนไล่น้ำหนักสีน้ำเงินกรมท่าโทนเดียวตามมาตรฐานราชการ
  * สรุป ๕ ลำดับโรงเรียนเดิมและจังหวัดที่มีผู้สมัครสูงสุด
* **ส่งออกข้อมูล (Export CSV/Excel):**
  * ส่งออกข้อมูลผู้สมัครเป็นไฟล์ CSV ตามรูปแบบงานทะเบียน พร้อม UTF-8 BOM เปิดใน Microsoft Excel ภาษาไทยได้ทันทีไม่เพี้ยน
* **หน้าตั้งค่าระบบ (Settings Panel):**
  * สวิตช์เปิด-ปิดระบบรับสมัคร
  * กำหนดวันเริ่มต้นและสิ้นสุดการรับสมัคร
  * แก้ไขรายชื่อสาขาวิชา ปวช. และ ปวส. แบบไดนามิก (ไม่ฮาร์ดโค้ด)
  * แก้ไขข้อความประกาศและเกณฑ์คุณสมบัติหน้าแรก

```text
├── index.html                  # หน้าเว็บหลัก Single Page Application (SPA)

├── js/
│   ├── app.js                  # ตัวควบคุมหลัก (Router, Form Handler, File Upload, Status)

│   ├── gas-api.js              # ระบบเชื่อมต่อ Google Apps Script Web App + LocalStorage Fallback
│   ├── pdf-generator.js        # ตัวสร้างใบสมัครทางการขนาด A4 พร้อมรูปถ่ายและเลขไทย

│   └── logo.png                # ตราสัญลักษณ์ทางการวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์
├── google-apps-script/
│   ├── Code.gs                 # จัดการ doGet, doPost API สำหรับ Web App
│   ├── Setup.gs                # สคริปต์สร้างฐานข้อมูล ๕ ชีตและโฟลเดอร์ Google Drive
│   ├── ApplicantService.gs     # บันทึกใบสมัคร, ตรวจเลขซ้ำ, สร้างรหัส Q70-xxxx
│   ├── DocumentService.gs      # บันทึกไฟล์แนบลง Google Drive แยกโฟลเดอร์ตามเลขที่สมัคร
│   ├── StatusService.gs        # จัดการสถานะ, มอบตัว, ออกรหัสนักเรียน 7020901xxxx
│   ├── NotificationService.gs  # ส่งแจ้งเตือนผ่าน LINE Notify และ Email
│   ├── PdfService.gs           # บริการสร้าง PDF ทางการบน Google Drive
│   └── appsscript.json         # Manifest และกำหนดสิทธิ์การเข้าถึง (OAuth Scopes)
├── README.md                   # คู่มือระบบและเอกสารประกอบ
└── DEPLOYMENT_GUIDE.md         # ขั้นตอนการติดตั้งบน Google Apps Script และ GitHub
```

## ๔. โครงสร้างฐานข้อมูล Google Sheets (๕ ชีต)

1. **`Applicants` (ทะเบียนผู้สมัคร):**
   `application_id`, `academic_year`, `level`, `prefix`, `first_name`, `last_name`, `full_name`, `birth_date`, `id_card`, `father_name`, `father_age`, `father_job`, `mother_name`, `mother_age`, `mother_job`, `house_no`, `moo`, `soi`, `road`, `subdistrict`, `district`, `province`, `postal_code`, `phone`, `current_grade`, `school_name`, `school_location`, `gpax`, `old_major`, `major_choice_1`, `major_choice_2`, `status`, `notes`, `student_id`, `enrolled_date`, `created_at`, `updated_at`
2. **`Documents` (รายการไฟล์แนบ):**
   `doc_id`, `application_id`, `doc_type`, `file_name`, `drive_file_id`, `drive_url`, `uploaded_at`, `verified`
3. **`StatusLog` (ประวัติการเปลี่ยนแปลงสถานะ):**
   `log_id`, `application_id`, `old_status`, `new_status`, `changed_by`, `role`, `notes`, `timestamp`
4. **`Staff` (บัญชีเจ้าหน้าที่):**
   `staff_id`, `username`, `password_hash`, `full_name`, `role`, `department`, `status`, `last_login`
5. **`Settings` (การตั้งค่าระบบและรายชื่อสาขาวิชา):**
   `setting_key`, `setting_value`, `description`, `updated_at`
